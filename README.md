# VeilleMedIA Jeunesses

> Une veille automatisée utilisant l'intelligence artificielle pour analyser la représentation des jeunesses dans les médias français sur les réseaux sociaux.

---

# 📖 À propos

La VeilleMedIA Jeunesses est un projet développé par Ashoka France afin de mieux comprendre comment les jeunesses sont représentées dans les médias français sur les réseaux sociaux.

Le projet combine une collecte automatisée des publications, des modèles de langage (LLM) et des phases de validation humaine afin de produire des indicateurs fiables sur les récits médiatiques concernant les jeunes.

Au-delà de la veille elle-même, le projet s'inscrit dans une démarche de transparence méthodologique. L'objectif est de documenter progressivement l'ensemble du pipeline, de partager les choix méthodologiques et d'améliorer continuellement la qualité des analyses.

---

# 🎯 Objectifs

Le projet poursuit plusieurs objectifs :

- Suivre l'évolution de la représentation des jeunesses dans les médias français.
- Produire des indicateurs fiables et des analyses dans le temps.
- Alimenter la recherche, le débat public et les actions de plaidoyer.
- Développer une méthodologie documentée, transparente et reproductible.
- Construire progressivement des outils ouverts autour de cette veille.

---

# ⚙️ Fonctionnement général

Le pipeline de la veille repose sur plusieurs grandes étapes :

1. Sélection des sources
2. Collecte automatisée des publications
3. Analyse par intelligence artificielle
4. Traitement et consolidation des données
5. Production des indicateurs et visualisations
6. Validation méthodologique et amélioration continue

La documentation détaillée de chaque étape est disponible dans les différents documents du dépôt.

---

# 📂 Organisation du dépôt
