# VeilleMedIA Jeunesses

> Une veille automatisée utilisant l'intelligence artificielle pour analyser la représentation des jeunesses dans les médias français sur les réseaux sociaux.

---

# 📖 À propos

La VeilleMedIA Jeunesses est un projet développé par Ashoka France afin de mieux comprendre comment les jeunesses sont représentées dans les médias français sur les réseaux sociaux.

Le projet combine une collecte automatisée des publications, des modèles de langage (LLM) et des phases de validation humaine afin de produire des indicateurs fiables sur les récits médiatiques concernant les jeunes.

Au-delà de la veille elle-même, le projet s'inscrit dans une démarche de transparence méthodologique. L'objectif est de documenter progressivement l'ensemble du pipeline, de partager les choix méthodologiques et d'améliorer continuellement la qualité des analyses.
